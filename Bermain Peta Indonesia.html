Mode Belajar
Petunjuk Mode Belajar (klik untuk membuka) Cara menggunakan Mode Belajar:
  1. Pilih kategori: Ibu kota provinsi, Laut, Samudra, atau Semua lokasi.
  2. Lihat warna titik pada peta sesuai legenda.
  3. Klik atau sentuh salah satu titik berwarna.
  4. Baca nama dan keterangannya pada kotak informasi di bawah tombol kategori.
Contoh: pilih “Ibu kota provinsi”, lalu klik titik merah di Kalimantan Timur untuk melihat Samarinda.
📍 Informasi lokasi akan tampil di sini.
Pilih kategori, lalu klik salah satu titik pada peta.
Petunjuk Mode Tantangan (klik untuk membuka) Cara bermain Mode Tantangan:
  1. Pilih kategori soal: Campuran, Ibu kota provinsi, Laut, atau Samudra.
  2. Tekan Mulai / Ulangi. Pertanyaan akan muncul.
  3. Klik titik yang menurutmu menunjukkan lokasi jawaban pada peta.
  4. Baca hasilnya, lalu tekan Soal berikutnya.
Benar dalam 60 detik = 100 poin; benar lebih dari 60 detik = 50 poin; salah atau melewati soal = 0 poin.
Tekan “Mulai / Ulangi” untuk memulai tantangan.
